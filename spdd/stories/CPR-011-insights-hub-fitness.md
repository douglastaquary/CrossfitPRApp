# CPR-011 — Hub Insights (Fitness-like) + Free teaser

**Personas:** Liberty → Independence (Free/PRO); Compete (Elite na mesma aba)  
**Design:** tipografia/métricas estilo Apple Fitness; identidade CrossfitPR (`AppDesign`)

## Como atleta Free / PRO / Elite

Quero ver **percepções** claras sobre minha evolução (tendências, platôs, metas, sessão recente),

para sentir valor imediato na aba Insights — e, no Free, um gostinho de PRO/Elite sem parede de vendas.

## Critérios de aceite

- [ ] PRO/Elite: hub com resumo numérico, última sessão (métricas), cards do WorkoutEngine, Elite, coach, ranking/charts
- [ ] Free: insight real (summary/trend) + gráfico ilustrativo + CTA upgrade (PRO/Elite)
- [ ] Empty states limpos (sem marketing longo no topo pago)
- [ ] Título da tab/screen recupera termo Insights / Percepções
- [ ] Tipografia via `AppDesign.Typography.*`; copy via `Strings.*`
- [ ] Fixtures + seed UITest para validar Free/PRO/Elite/empty/Watch
