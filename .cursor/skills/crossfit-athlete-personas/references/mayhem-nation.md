## Escala de níveis (Mayhem Gym)

Usar estes nomes no **modelo mental interno** e em insights; na UI preferir termos localizados via `Strings.*` (ex.: Iniciante / Intermediário / Rx / Compete) salvo decisão de Design.

| Nível | Quem | % típica no gym |
|-------|------|-----------------|
| **Liberty** | Beginner / scale | Maioria relativa de iniciantes |
| **Independence** | Intermediate | Bulk da classe |
| **Freedom (Prescribed / Rx)** | Rx full | ~5–10% chasing Rx |
| **Compete (Rx+)** | Competitive / extra volume | Fatia pequena, alta intenção |

Coaches tratam níveis como **âncoras aspiracionais**, não regra rígida — o app deve permitir override manual do nível sugerido.

## Sessão-tipo Compete (~90–120 min)

Estrutura observada em samples Mayhem Compete:

1. **Activation** — Crossover Symmetry / Banded 7s; Mayhem Hip Halo  
2. **Movement prep** — bike/row/run + lunges ou skill transfer  
3. **Workout prep** — 1 set no pace do WOD  
4. **Metcon** — séries com rest 1:1; target stimulus explícito  
5. **Strength** — %1RM **e/ou** RPE (ex.: EMOM DL @ 7–8.5/10)  
6. **Cool-down** — cardio leve + mobilidade  

**Tempo:** 1:30–2h; se não couber → Mayhem 60.  
**Missed day:** retomar sem punição — UX sem guilt streaks destrutivos.

## Princípios de treino (para engine e coach)

1. **Stimulus manda** — % e kg são guia; qualidade do movimento e intenção do dia vencem.  
2. **Target scores** — "most athletes 3:00–4:30" cria feedback objetivo pós-WOD.  
3. **Periodização sazonal** — Open → Quarter/Semis → Games (ou deload).  
4. **Limiting factors** — Performance Coaching Mayhem: assessment vs field → gaps → plano. Espelho do Elite CrossfitPR.  
5. **Coach-first** — explicar *por quê*; insights do app devem ensinar, não só ranquear.  
6. **Multi-track** — mesmo atleta usa força + engine + skill; assessment por domínio.  
7. **RPE + %** — registrar ambos quando possível (Watch fase 2 / log iPhone).
